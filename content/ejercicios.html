Cómo usar este apéndice

Treinta preguntas sobre el Banco de Sangre, ordenadas de menor a mayor dificultad. Intenta resolverlas antes de mirar la solución. No importa si tu consulta se ve distinta: importa que responda la pregunta y que puedas explicar por qué.

Requisito: haber ejecutado 00_esquema.sql y 01_datos_demo.sql. Las respuestas usan los datos de demostración; algunos totales cambiarán si agregas movimientos. Si ejecutaste el despacho de ejemplo del capítulo 12, vuelve a cargar 01_datos_demo.sql antes del reto 10.

17. Primero y último movimiento por unidad

Para cada unidad, muestra su primer y su último movimiento.

WITH ranked AS (
  SELECT
    id_unidad,
    tipo_movimiento,
    fecha_movimiento,
    ROW_NUMBER() OVER (PARTITION BY id_unidad ORDER BY fecha_movimiento) AS rn_primero,
    ROW_NUMBER() OVER (PARTITION BY id_unidad ORDER BY fecha_movimiento DESC) AS rn_ultimo
  FROM movimientos_inventario
)
SELECT
  id_unidad,
  tipo_movimiento,
  fecha_movimiento,
  CASE WHEN rn_primero = 1 THEN 'primero' ELSE 'ultimo' END AS momento
FROM ranked
WHERE rn_primero = 1 OR rn_ultimo = 1
ORDER BY id_unidad, fecha_movimiento;

Reto 4. Solicitado frente a despachado

Compara, por componente, la cantidad solicitada y la cantidad de unidades despachadas.

WITH solicitado AS (
  SELECT tipo_componente, SUM(cantidad) AS unidades
  FROM solicitud_detalle
  GROUP BY tipo_componente
),
despachado AS (
  SELECT u.tipo_componente, COUNT(*) AS unidades
  FROM despacho_detalle dd
  JOIN unidades_sangre u ON u.id_unidad = dd.id_unidad
  GROUP BY u.tipo_componente
)
SELECT
  s.tipo_componente,
  s.unidades AS solicitadas,
  COALESCE(d.unidades, 0) AS despachadas,
  s.unidades - COALESCE(d.unidades, 0) AS diferencia
FROM solicitado s
LEFT JOIN despachado d ON d.tipo_componente = s.tipo_componente
ORDER BY diferencia DESC;

Reto 10. Despacho transaccional

Registra el despacho de la unidad 9 para la solicitud 5, actualiza su estado y deja el movimiento de inventario. Todo en una transacción.

START TRANSACTION;

INSERT INTO despachos (id_solicitud, responsable, destino, estado)
VALUES (5, 'Lic. Ana Prado', 'Hospital Ángeles', 'preparando');

SET @id_despacho = LAST_INSERT_ID();

INSERT INTO despacho_detalle (id_despacho, id_unidad)
VALUES (@id_despacho, 9);

UPDATE unidades_sangre
SET estado = 'despachada', ubicacion = 'Hospital Ángeles'
WHERE id_unidad = 9
  AND estado = 'reservada';

-- Verifica que el UPDATE cambió una fila antes de confirmar
SELECT ROW_COUNT() AS filas_actualizadas;

INSERT INTO movimientos_inventario
  (id_unidad, tipo_movimiento, fecha_movimiento, usuario, motivo)
VALUES
  (9, 'salida', NOW(), 'ana.prado', 'Despacho solicitud 5');

COMMIT;

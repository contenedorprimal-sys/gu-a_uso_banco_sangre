Cómo usar este cuaderno

El sitio está pensado para leerse de principio a fin, pero también para consultarse como referencia. Cada capítulo mezcla explicación, código y una conexión explícita con el proyecto del banco de sangre.

  • Portada: mapa del recorrido, el caso y las cifras del proyecto.
  • Barra lateral: agrupa los capítulos por fase. En móvil se abre con el botón de menú.
  • Índice derecho: muestra las secciones de la página actual y marca dónde estás.
  • Paginación: al final de cada capítulo hay enlace al anterior y al siguiente.

Buscar

Pulsa Ctrl + K (o ⌘ + K en macOS), o la tecla /, para abrir la búsqueda. Escribe un tema, una función o una idea; muévete con ↑ y ↓ y abre con Enter. Esc cierra.

La búsqueda indexa títulos, resúmenes, ideas clave y el texto de los capítulos. No necesita internet.

Copiar código

Cada bloque de código tiene un botón Copiar en la esquina superior derecha. El comando o consulta se copia tal cual, sin los números de línea (no hay números de línea).

Los bloques están etiquetados por lenguaje: SQL, BASH o TEXTO.

Ejecutar el proyecto

Los scripts están en proyecto/sql/. Se ejecutan en este orden:

00_esquema.sql
01_datos_demo.sql
02_unidad2_espacio_particiones_eventos.sql
03_unidad3_seguridad_monitoreo_auditoria.sql
04_unidad4_respaldo_recuperacion.sql
04_respaldo_incremental.sh   (terminal)
05_unidad5_afinacion.sql

En MySQL Workbench: File → Open SQL Script, selecciona el archivo y ejecuta con el rayo. Para ejecutar por bloques, selecciona el bloque y usa Execute Current Statement.

Antes de empezar

Los scripts 00 y 01 borran y recrean la base banco_sangre. No los ejecutes en un servidor con datos reales. Usa una instalación local o un contenedor.

Requisitos

  • MySQL 8.x (o MariaDB 10.6+ con pequeños ajustes).
  • MySQL Workbench, DBeaver o la terminal mysql.
  • Permisos para crear bases, usuarios, roles y eventos.
  • Para la unidad 4: mysqldump, mysqlbinlog y un directorio de respaldo.

Diseño y accesibilidad

  • Objetivos táctiles de al menos 44 × 44 px en móvil.
  • Foco visible en todos los controles.
  • Contraste alto en texto y código.
  • Tema claro y oscuro según la preferencia del sistema, sin interruptor propio.
  • Respeta prefers-reduced-motion: desactiva animaciones y desplazamiento suave.
  • Tipografía local: no se descarga nada al abrir la página.
  • Enlace «Saltar al contenido» para teclado.

Después de editar contenido, regenera el sitio:

cd sitio
python3 build/build.py

Sin servidor

Puedes abrir sitio/index.html con doble clic. Todo el contenido viaja en assets/content.js y las fuentes son locales. No hay peticiones de red, cookies ni rastreadores.

Si prefieres servirlo por HTTP:

cd sitio
python3 -m http.server 8000

Y visita http://localhost:8000.

Fórmulas que hay que memorizar

Tamaño de fila = suma de bytes de cada columna

Datos = tamaño de fila × número de filas

Índices = +10 % a +30 % (en clase se usa 20 %)

Crecimiento = × 1.20 a × 1.30

Disponibilidad = (minutos totales − caída) / minutos totales × 100

Año = 525,600 minutos

Quorum = nodos disponibles > total / 2

Comandos esenciales

-- Espacio real por tabla
SELECT table_name,
  ROUND((data_length + index_length)/1024/1024, 2) AS total_mb,
  ROUND(index_length/NULLIF(data_length+index_length,0)*100, 2) AS pct_indices
FROM information_schema.TABLES
WHERE table_schema = 'banco_sangre';

-- Tamaño por base
SELECT table_schema,
  ROUND(SUM(data_length + index_length)/1024/1024, 2) AS total_mb
FROM information_schema.TABLES
GROUP BY table_schema;

-- Particiones de una tabla
SELECT partition_name, table_rows
FROM information_schema.PARTITIONS
WHERE table_schema = 'banco_sangre' AND table_name = 'movimientos_inventario';

-- Uptime
SELECT VARIABLE_VALUE FROM performance_schema.global_status
WHERE VARIABLE_NAME = 'Uptime';

-- Eventos
SHOW EVENTS FROM banco_sangre;

-- Privilegios
SHOW GRANTS FOR 'lab_user'@'localhost';

Reglas que cuestan puntos

Particiones

  • La columna de partición debe ser parte de la PRIMARY KEY.
  • Una tabla particionada no puede tener FOREIGN KEY.
  • Para VARCHAR usa LIST COLUMNS.
  • RANGE para fechas; LIST para categorías; HASH para reparto uniforme.
  • Un INSERT con un valor fuera de las particiones LIST falla.

Eventos y clúster

  • Primero SET GLOBAL event_scheduler = ON; y verifica con SHOW VARIABLES.
  • Quorum = más de la mitad; usa número impar de nodos.
  • Sin quorum no hay escrituras (anti split-brain).
  • Failover: detección → elección (menor server_uuid) → redirección → recuperación.
  • Una transacción sin COMMIT no se replica y no continúa en otro nodo.

Respaldos y afinación

  • mysqldump --single-transaction para InnoDB sin bloquear.
  • Incluye --routines --triggers --events.
  • El binlog permite recuperación punto en el tiempo.
  • Un índice compuesto se ordena: igualdad → rango → orden.
  • Mide con EXPLAIN antes y después; sin línea base no hay evidencia.
